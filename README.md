# branded-types

Branded types: `Branded<Base, Name>` gives a base type a nominal brand, so an identifier of one kind cannot be passed where another is expected, and `isNonEmptyString` checks an unknown value at the boundary.

## Packages

- `@ai-swfactory-oss/branded-types`: the branded types (a package of kind sdk: pure types and functions; it takes no ports).
