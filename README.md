# branded-types

Zod-backed branded string types: nominal string types whose values are checked at the boundary, so an identifier of one kind cannot be passed where another is expected.

The code arrives by migration from the private ai-swfactory/branded-types (part of the ai-swfactory/seams migration); this repository currently holds only its guarded skeleton.

## Packages

- `@ai-swfactory-oss/branded-types`: the branded string types (a vocabulary package: pure types and functions).
